# codecruz plugins for Claude Code

[Español](README.es.md)

One marketplace for the Claude Code plugins published by
[codecruz](https://github.com/codecruz). Each plugin lives in its own
repository; this one only lists them.

```
/plugin marketplace add codecruz/claude-plugins
```

Then install the ones you want and start a new session, or run
`/reload-plugins`.

| Plugin | What it does | Install |
| --- | --- | --- |
| [langstats](https://github.com/codecruz/langstats) ([website](https://codecruz.github.io/langstats/)) | Tracks the languages Claude works in and publishes them to your GitHub profile README. | `/plugin install langstats@codecruz` |
| [annotate](https://github.com/codecruz/annotate) ([website](https://codecruz.github.io/annotate/)) | Annotate your locally running site in the browser and let Claude carry out the notes. | `/plugin install annotate@codecruz` |
