# codecruz plugins for Claude Code

One marketplace for the Claude Code plugins published by
[codecruz](https://github.com/codecruz). Each plugin lives in its own
repository; this one only lists them.

```
/plugin marketplace add codecruz/claude-plugins
```

| Plugin | What it does | Install |
| --- | --- | --- |
| [langstats](https://github.com/codecruz/langstats) | Tracks the languages Claude works in and publishes them to your GitHub profile README. | `/plugin install langstats@codecruz` |
| [annotate](https://github.com/codecruz/annotate) | Annotate your locally running site in the browser and let Claude carry out the notes. | `/plugin install annotate@codecruz` |
