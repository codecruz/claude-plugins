# Plugins de codecruz para Claude Code

[English](README.md)

Un único marketplace para los plugins de Claude Code que publica
[codecruz](https://github.com/codecruz). Cada plugin vive en su propio
repositorio; este solo los lista.

```
/plugin marketplace add codecruz/claude-plugins
```

Después instala los que quieras y abre una sesión nueva, o ejecuta
`/reload-plugins`.

| Plugin | Qué hace | Instalación |
| --- | --- | --- |
| [langstats](https://github.com/codecruz/langstats) ([web](https://codecruz.github.io/langstats/)) | Registra los lenguajes en los que trabaja Claude y los publica en el README de tu perfil de GitHub. | `/plugin install langstats@codecruz` |
| [annotate](https://github.com/codecruz/annotate) ([web](https://codecruz.github.io/annotate/)) | Anota en el navegador la web que tienes en local y deja que Claude aplique las notas. | `/plugin install annotate@codecruz` |
